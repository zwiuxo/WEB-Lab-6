**📌 Описание задания**
- Изучить работу с нереляционными СУБД: **Redis**, **Elasticsearch** и **ClickHouse**.
- Научиться взаимодействовать с ними из PHP через HTTP-запросы с помощью библиотеки **Guzzle**.
- Реализовать тематическое задание (Соцсеть) на базе поискового движка Elasticsearch.

**⚙️ Как запустить проект**
1. **Установка библиотек (Composer):**
Так как папка `vendor` не загружается в репозиторий, её нужно создать командой (выполнить в папке проекта):
```bash
docker run --rm -v \${PWD}/www:/app composer install
```

2. **Запуск контейнеров:**
```bash
docker-compose up -d --build
```
3. **Проверка:**
- Откройте в браузере: [http://localhost:8080](http://localhost:8080)

**📂 Содержимое проекта**
- `docker-compose.yml` — описание 5 сервисов: Nginx, PHP, Redis, Elasticsearch, ClickHouse.
- `Dockerfile` — сборка PHP с поддержкой Composer и необходимых системных утилит.
- `www/ClientFactory.php` —  класс для создания Guzzle-клиентов.
- `www/RedisExample.php` — работа с Redis (хранение статусов).
- `www/ElasticExample.php` —  задание 16 (поиск пользователей в соцсети).
- `www/ClickhouseExample.php` — работа с аналитической БД ClickHouse.
- `www/index.php` — главная страница, объединяющая результаты запросов ко всем БД.

**✅ Результат**
Проект успешно демонстрирует работу с тремя типами нереляционных баз данных. Реализована индексация и поиск пользователей по тегам и интересам в Elasticsearch, хранение данных в Redis и ведение аналитических логов в ClickHouse. Все запросы выполняются через API с использованием GuzzleClient.
